Account

You do not need an account to play. An account lets you tie your in-game player key to your name, and it is how people get permission to upload old demos or host a server.

Usernames are 3 to 24 letters, digits, _ or -. Passwords are at least 10 characters. We send one mail to confirm the address.

Permissions: Admin area →

Permissions only work once your email address is confirmed.

Demo uploads

You can upload old client demos. Add demos

Uploading old client demos needs permission. If you have an old demo upload key, enter it once to upgrade this account: it gets upload permission and takes over what that key uploaded. The key is not used for anything else. Otherwise ask an admin.

Your servers

Public servers that anyone can join can be listed here. A server must be reachable from the internet over UDP (the game port) and over a secure WebSocket (wss:// with a valid certificate), so browsers can join too. An admin approves each one.

Put this in the server's configuration (it is shown once and works for one registration):

Also set AGENT_REGISTRATION_URL (this site), AGENT_PUBLIC_NAMES (the public game address as host:port) and AGENT_PUBLIC_URL (the https address of the agent), then start the server. It shows up here once the site has reached it.
