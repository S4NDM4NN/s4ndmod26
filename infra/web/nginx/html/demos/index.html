Demo replays

Old Return to Castle Wolfenstein client demos (.dm_57, .dm_59, .dm_60) made into 3D replays. A demo only shows what its player could see, so a game gets better the more players' demos of it there are: they are lined up on the server clock and merged. Anyone can watch. Adding demos needs an uploader key; the key that uploaded a demo can also remove it.
